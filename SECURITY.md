# Security Policy

## Reporting a Vulnerability
Please report security vulnerabilities privately by email to admin@robotsix.net.
Do not open a public issue for security problems.

## Response Time
This project is maintained by a single person and cannot guarantee a response
time. Reports are handled on a best-effort basis.

## Coordinated Disclosure
Please give the maintainer a reasonable opportunity to investigate and release
a fix before any public disclosure. Reported vulnerabilities will be handled
under a coordinated-disclosure approach.
